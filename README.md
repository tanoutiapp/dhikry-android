# Dhikry – Android

Dhikry t'aide à tenir ton objectif quotidien d'istighfar et de dhikr : compteur automatique, rappels, séries, défis entre amis.

## Télécharger

👉 **[Télécharger Dhikry pour Android (APK)](https://github.com/tanoutiapp/dhikry-android/releases/latest/download/Dhikry.apk)**

## Installer

1. Ouvre le lien ci-dessus sur ton téléphone Android et télécharge le fichier.
2. Ouvre le fichier `Dhikry.apk` téléchargé.
3. Si Android le demande, autorise l'installation depuis cette source (Chrome ou Fichiers), puis appuie sur **Installer**.

Pour mettre à jour, télécharge la nouvelle version depuis le même lien et installe-la par-dessus : tes données sont conservées.

Sur iPhone, Dhikry est disponible sur l'App Store.

Confidentialité : https://istighfar-app.expo.app
